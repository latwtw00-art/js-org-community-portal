4-Step Procedure
1 GitHub Pages Help

GitHub Page Setup

If you haven't already, now it's time to log in to your GitHub account and set up your GitHub Page by following the official instructions. Make sure to add some reasonable content with a clear connection to JavaScript!

2 Wiki Details

Pick Subdomain

Now you should determine your js.org subdomain: either choose your username or the name of your repo according to the existing GitHub Pages URL (for http://foo.github.io/bar, either "foo.js.org" or "bar.js.org" would be possible).

3 Custom Domains Help

Add CNAME File

Add a file named "CNAME" to your repo root (or gh-pages branch) containing a single line matching your chosen domain (e.g. "foo.js.org" without quotes).

4 Open Pull Request

Submit Pull Request

To finish the procedure, make a pull request in our GitHub repository (js-org/js.org) adding your subdomain to cnames_active.json. Your new URL should go live within 24 hours!

Terms, Privacy & Imprint

1. JavaScript Connection: The provided service is strictly dedicated to the JavaScript community. Only repositories with an explicit connection to JavaScript or its ecosystem qualify (libraries, frameworks, tools, engines, learning resources).
2. Content Responsibility & Ownership: The operators of JS.ORG do not host, store, or edit any code published on users repositories. The repository owner maintains full copyright and legal liability for all material displayed on their subdomain.
3. Fair Use & Reserved Names: Trademarks, famous brands, and names reserved for administrative infrastructure are strictly off-limits. Subdomains registered for trademark squatting, phishing, or abusive activities will be rejected or revoked immediately.
4. Pruning Policy: Abandoned or inactive domains (e.g. repos that 404 or show GitHub Page not found errors for sustained periods) are subject to pruning in accordance with community guidelines to keep the directory clean.
5. Privacy Statement: JS.ORG does not log personal identifiable information or sell visitor metrics. GitHub Pages handles the underlying web server logs per GitHub's Privacy Statement.
